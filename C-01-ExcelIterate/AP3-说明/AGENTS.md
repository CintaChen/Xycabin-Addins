# 一. 开发接手入口

## 1. 阅读顺序

先完整阅读[开发日志](开发日志.md)：[项目档案](开发日志.md#二-项目档案)核对当前源码/状态，[共享开发经验](开发日志.md#三-word与excel共享开发经验)查实现方法，[共享维护纪律](开发日志.md#四-word与excel共享维护纪律)查交付/清理，最后读本宿主第五章与[使用说明](使用说明.md)。知识以当前源码文档为准，不依赖旧聊天或隐藏记忆；本目录为唯一入口。

## 2. 共享与网站

共享正文和公共源码同步姊妹项目，运行父目录verify_shared.py及两产品文档门禁。网站唯一在[C-03](../../C-03-Website·Xycabin/AP3-说明/AGENTS.md)，单加载项重建也携带完整Website；联合交付使用网站入口，不恢复网站或维护文档副本。

## 3. 交付边界

沿用原版本、固定证书/私钥和稳定ID。先固定非审计正文，再重建/签名/打包/验证，最后回填delivery-audit；后台、历史及真实验收分开记录。构建不安装、不关闭WPS。文档改动不触发[冗余清理](开发日志.md#4-冗余文件清理)；实际清理指令才按正文执行。

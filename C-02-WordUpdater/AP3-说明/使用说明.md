**WordUpdater · 使用说明**

<!-- agent-overview:start -->

# 一. 安装与启用

　　当前版本 **0.9.9.1**。WordUpdater 为 WPS 文字提供逐格链接 Excel、更新和查看链接，以及正文表格选择。

## 1. 安装 [Microsoft VSTO 运行库](https://www.microsoft.com/en-us/download/details.aspx?id=105890)

　　点击 Download，下载并运行 `vstor_redist.exe`。

## 2. 保存文件

　　完全退出 WPS，包括后台进程。

## 3. 运行 [WordUpdater\_Setup.exe](../AP1-程序/WordUpdater_Setup.exe)

　　选择位置并点击“安装”。

## 4. 在“Microsoft Office 自定义项安装程序”中完成授权

　　等待安装器显示成功。

## 5. 打开 WPS 文字

　　确认出现“WordUpdater”选项卡。

　　取消授权或安装失败时尚未安装完成。卸载时先保存文件并退出 WPS，再运行同一安装器，点击“卸载”。

　　常用顺序：复制表格区域→在文字表格中选中同样格数→链接Excel→源数据改变后更新链接。“查看链接”检查整篇文档，“全选表格”便于统一格式；扩展组的 Agent-Evo。修改前保存文档。

# 二. 功能操作

　　弹窗数据网格表头完整单行显示、居中且默认加粗；可在“自定格式”中明确关闭粗体。拖动列边界可以调宽，不能缩窄至截断表头；窗口较窄时用横向滚动条查看其余列。该规则不改变数据内容和正文样式。

　　这里的数据网格指弹窗中的来源清单和链接明细，不改变文档表格的列宽或字体。

## 1. 链接Excel

### (1). 在 WPS 表格中复制源区域

　　例如 A1:B2，共 4 格。

### (2). 切到 WPS 文字

　　用鼠标拖选目标表格中的规则矩形，例如 2×2，共 4 格。

### (3). 点击“链接 → 链接Excel”

　　核对建立及刷新结果。 **只写入选中的目标矩形，源与目标格数必须相等，原内容会被覆盖。** 两边按先行后列对应：A1、B1、A2、B2 依次进入目标 4 格。只点一个格子表示只选 1 格，不会自动扩展到整表。

　　支持源区域 Ctrl 多选，按子区域顺序及各区域的先行后列排列。例如复制 H1、H3，可对应文字中的两个格子。**多选复制后请保持 WPS 表格打开，并核对映射。** WPS 剪贴板可能只记录包围范围；若目标格数恰好与该范围相等，仍可能按整段处理，必要时逐块复制。

　　目标不能跨表、越出表格，不能含合并、拆分或嵌套单元格；单次最多 500 格。预检失败时不写入，执行中失败按实际结果报告。源文件须仍在原位置，且可以保持打开。撤销效果依宿主，请先保存文档，勿只依赖 Ctrl+Z。

## 2. 更新链接

### (1). 选中包含链接的文字或表格

　　Ctrl+A 可选整篇文档。

　　点击“链接 → 更新链接”。

### (2). 查看发现数、成功数、失败原因和变化明细。

　　支持本加载项建立的链接，也支持 WPS“选择性粘贴 → 粘贴链接”建立的链接。变化内容临时标黄；关闭结果窗口后滚动到第一个变化处，约 2.5 秒后恢复原底色。

　　未选内容或选区没有链接时会提示。个别更新失败会跳过并列明原因，失败项不计为变化。图片/OLE 对象照常更新，但不参加文字变化统计。

　　源文件未打开时，WPS 可能临时启动后台表格读取数据；程序仅记录相关后台实例，不自动关闭或强制结束；源文件可能仍被占用，请保存工作后自行确认关闭对应WPS。重复更新或关闭链接窗口会提前恢复临时标黄。

## 3. 查看链接

　　点击“链接 → 查看链接”，无需先选内容。上方按源文件分组，下方列出所选文件的链接明细；范围包含正文、页眉页脚和脚注等内容。

| 操作              | 结果                       |
| --------------- | ------------------------ |
| 更新所有链接          | 更新整篇文档的全部链接              |
| 中断所有链接          | 两次确认后转成静态内容或图片；恢复需重新建立链接 |
| 打开源文件 / 双击上方条目  | 打开来源；缺失或打开失败时提示定位文件      |
| 复制路径            | 复制所选源文件的完整路径             |
| 跳转到该字段 / 双击下方条目 | 跳到链接位置并标黄约 2.5 秒         |
| 刷新列表            | 文档修改后重新扫描                |

　　“更新方式”显示自动、手动或混合；“源文件缺失”表示文件不在原位置。文档改动导致定位失效时，先刷新列表。

　　窗口可以保持打开，同时编辑文档或到表格中改数据。同一文档重复点击会显示已有窗口；Esc 或右上角 × 关闭。“更新链接”仅处理选区，本窗口可处理整篇文档。

## 4. 全选表格

　　点击“操作 → 全选表格”，选中正文中的全部顶层表格，再使用字体或表格工具统一格式。

　　仅选择，不修改内容；不包含页眉、页脚、文本框或嵌套表格，不滚动页面。全部选中时不弹窗；部分失败会提示数量，可手工 Ctrl 补选。文档处于表单填写保护状态时，请先停止保护。

## 5. Agent-Evo、自定配置与实验计划

　　点击“扩展 → Agent扩展”显示 Agent-Evo，再次点击隐藏；选择按用户记住。

### (1). 调用API

　　调用API 下分智能云-API（百度智能云、阿里智能云控制台）和 Agent-API；Agent-API 再分国内Agent（WorkBuddy、TRAE、Qoder、DeepSeek、豆包、Kimi）与国外Agent（ChatGPT、Claude、Gemini），选择后在默认浏览器打开。

### (2). 开发流程

　　开发预览、用户预览显示概览，可选择和复制；“全文”每次选择电脑中的应用打开，配图随文档离线导出。开发全文每次先验证口令，提示“请输入开发者的微信名称”；输入区分大小写，忽略两端空白，取消不打开全文。用户全文无需口令；验证只保护按钮入口，已导出的文件未加密。XyCabin 打开[离线小屋](../../C-03-Website·Xycabin/AP3-说明/使用说明.md)。Esc 关闭预览窗口。

### (3). 自定配置 → 交互弹窗

　　展开菜单树，填写窗口宽高后保存；两项同时留空使用默认。

　　点击“自定调整”可拖动真实布局预览，关闭后只更新该行草稿；点击“保存设置”才保存，再次调整沿用草稿。预览不执行业务。尺寸指窗口内部区域，必须满足表中最小值。

　　“恢复选中默认”覆盖选中菜单下全部窗口，“恢复全部默认”覆盖所有登记窗口，均需保存。“重新加载”会丢弃当前编辑；出现冲突或“未保存”时，重新加载再调整。普通功能窗口的临时拖动不保存；设置窗口自身只读预览，系统窗口、浏览器及安装器不在调整范围内。

### (4). 自定配置 → 自定排序

　　子项左侧六点表示可拖拽；蓝色+/−展开或收起菜单。拖动子项、上下移动或填写顺序号，保存后立即生效；只调整同一菜单中的子项。

### (5). 自定配置 → 自定名称

　　蓝色+/−展开或收起菜单，再填写命令或子菜单的新名称并保存；清空恢复原名，功能与图标保持原有对应关系。

### (6). 自定配置 → 自定格式

　　先选择窗口，再在控件树或预览中选择控件，修改固定文字、字体或颜色。“粗体、斜体、文字颜色”在同一行；下一行点击“调整控件缩放”，拖动选中控件右侧、底部或右下角的蓝色手柄，调整宽度或高度，不改变字号。Esc 取消本次拖动。下拉框和数字框只能调整宽度，高度随字号变化。可单独恢复默认尺寸；整个窗口大小请用“交互弹窗”。草稿实时预览，保存后下次打开对应弹窗时生效，无须重启WPS；取消编辑不保存。预览不执行业务，也不替换数据、路径或用户输入。窗口入口可悬停查看，左侧目录可拖动分隔条加宽。

### (7). 实验计划 → 需求记录

　　记录待改善的功能，点击保存，下次打开可继续编辑。两加载项分别保存；重新读取会放弃未保存编辑。宿主退出时保留未保存草稿，下次打开可选择恢复。

### (8). 实验计划 → OCR识别

　　本版为灰色占位项。Excel 的可用 OCR 位于“文件操作 → 文件提取名称”。

　　**名称、排序保存后立即生效；格式、控件缩放和弹窗尺寸在下次打开对应弹窗时生效。** 已打开的弹窗保持原样，关闭后重新打开即可，无须重启WPS。取消编辑不保存。

　　排序、名称和格式均可恢复默认；这些设置只作用本加载项。格式设置不包含安装器、系统窗口和浏览器。

　　提示和确认窗口关闭后，可继续编辑文档；涉及修改的操作仍须明确确认。

## 6. 修改默认配置后重新打包

　　保存Word、Excel的Configure_program.py及网站Configure_Site.py后，运行网站项目的“一键重建并打包.bat”。进入后按1进行增量检查，按2进行完整验证。首次或相关内容有变化时，增量会自动补做需要的步骤；准备正式发布时选2。两种方式都会核对两个安装包与网站内容的一致性，无须先运行两个单项目批处理。

　　构建结束后，保存文件并完全退出WPS，再分别重新安装两个安装包。构建本身不会自动安装。桌面照片不参与默认打包测试，也不会被项目清理自动删除。

## 7. 术语对照

　　为便于描述功能与反馈问题，本说明统一使用下列称呼指代弹窗中的各类元素。

| 称呼    | 指代的元素        | 典型位置                          |
| ----- | ------------ | ----------------------------- |
| 卡片    | 圆角白底边框的容器区块  | 查看链接的概览与明细区                   |
| 网格    | 窗口中有行有列的数据表  | 查看链接的源文件清单、链接明细；不等于文档中的Word表格 |
| 文本框   | 独立输入或只读文本区域  | 自定名称编辑、需求记录、文档预览              |
| 下拉框   | 独立选项选择       | 自定格式的窗口/字体选择                  |
| 网格单元格 | 界面网格中的一个格子   | 链接清单一行中的文件路径、更新方式等            |
| 按钮    | 圆角命令按钮       | 更新所有链接、复制路径、关闭                |
| 标签    | 文字说明         | 各区域标题与状态说明                    |
| 菜单树   | 可展开的命令层级     | 自定排序/名称，以及交互弹窗目录              |
| 手柄    | 调整尺寸或顺序的操作标记 | 名称输入框右侧拖宽、自定格式蓝色缩放柄、自定排序六点柄   |

　　组合描述更精确，如“查看链接的来源网格”或“自定名称的文本框”。文档表格单元格与弹窗网格单元格是不同对象。

# 三. 常见问题

## 1. 没有选项卡或安装失败

　　确认运行库已安装且安装器明确显示成功，保存并完全退出 WPS 后重装。安装日志在 `%LocalAppData%/WordUpdater/SetupLogs/`。

## 2. 链接失败或内容不对应

　　检查目标矩形、两边格数、500 格上限、合并单元格和源文件位置；Ctrl 多选请保持表格打开，必要时逐块复制。

## 3. 源文件找不到

　　从“查看链接”定位来源，检查移动、改名、权限及网络盘连接。

## 4. 跳转位置不对

　　文档改动后先点击“刷新列表”。

## 5. 能否同时打开文字和表格

　　可以。源数据更新后，再选中文字目标范围并点击“更新链接”。

# 四. 获取帮助

　　点击“反馈 → 问题反馈”，打开 QQ 邮箱网页版后自行登录并发送。邮箱地址可在按钮悬停提示中查看。

　　提供版本、操作步骤、错误提示和日志。运行日志在 `%LocalAppData%/WordUpdater/WordUpdater.log`。开发方法、共享维护纪律及Word专属经验请查[开发日志](开发日志.md)；AI 接手入口见[AGENTS.md](AGENTS.md)。

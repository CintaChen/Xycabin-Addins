# 二. 项目档案

## 1. 定位、关系与源码地图

网站介绍两个加载项，提供指南/版本/下载、开发流程、反馈与音乐；邮件/网盘需要网络。HTML内嵌CSS、JS、SVG、MP3和下载指引PNG，无CDN、外部字体、fetch邻近文件依赖。AP1-程序/XyCabin.html独立网页含两EXE；两DLL资源是同一无EXE快照。Website不是第三个WPS加载项，不产第三份EXE。

| 当前源码 | 职责 |
| --- | --- |
| AP1-程序/Configure_Site.py | 唯一品牌、文案、指南、版本、颜色、声音和下载配置 |
| src/site_core.py、site_template.html | 校验/转义/序列化、单页布局及通用交互 |
| src/site_audio.js、site_downloads.js | 音频状态机、下载解码/菜单/弹窗 |
| src/assets/tranquility.mp3、unblock-guide.png | 必需项目内音乐片段与下载提示图，普通重建不依赖开发机原文件 |
| rebuild.py、src/delivery.py、build_cache.py | 固定快照、两包暂存、联合验证/事务发布/回滚、内容缓存 |
| validate.py、src/tools | 前端、目录/文档、资源、事务、无旧build集成与清理探针 |

三个输出区统一AP1-程序（唯一HTML/配置/批处理）、AP2-美工（当前PNG）、AP3-说明（三份文档）；build留工具、收据与证据。两加载项不保留网站模板副本；相关输入路径按脚本位置计算。

## 2. 携带源码复现

完整交付带三个同级项目、父verify_shared.py、两加载项lib、原证书私钥和项目内资产；仅重建单加载项也带完整Website。环境：Windows、可执行Python≥3.10、Node.js、.NET Framework4.8/C#5。先实际--version核解释器，子进程参数列表/UTF-8；普通构建不需网络或FFmpeg。

预览运行 `python AP1-程序/Configure_Site.py`，只改HTML；仅使用成功交付记录中版本/大小/摘要匹配的包，无记录或变更时默认下载不可用。不要手改生成HTML或把配置器移出固定目录。

联合交付直接运行本项目AP1批处理：1增量、2完整（均--background），或 `python rebuild.py --background --mode full`，不必先跑两单项目批处理。随后 `python validate.py --background`；回填审计后 `python src/tools/layout_probe.py --strict-evidence`核引用。安装、真实file下载/播放、WPS点击单列验收。

# 三. XyCabin项目维护纪律

## 1. 文档、版本与经验归属

AGENTS是阅读/同步入口；使用说明是打开、指南、下载、音乐和帮助；开发日志保存实现方法、边界、入口和证据。网站只维护前端经验，不复制宿主公式/字段事务。新经验归对应主题，保留独有失败/恢复结论，改指南时核两宿主适用性；无新增经验如实说明。不新增维护MD副本。

三份文档最多五级，编号后一个半角空格：`# 一. 标题`→`## 1. 标题`→`### (1). 标题`→`#### a. 标题`→`##### i. 标题`；同级连续、新父重置，五级i./ii./iii.小写罗马，不跳级、不强凑五层，代码围栏排除。顶部仅一个更新日期，目录/锚点同步；概览与delivery-audit标记唯一有序，目录在概览外。门禁同时查三项目九文档。

版本从两加载项INSTALLER_VERSION读取，用户未指定不递增。PRODUCTS版本新到旧、摘要与对应日志逐字一致，每版最多150字，每个功能按1.、2.编号。公共方法在两加载项第三、四章逐字同步，公共源码字节同步；网站指南以对应使用说明为准。

维护顺序：对照最终实现→提炼做法/边界/入口/证据→更新正文、指南与配置→文档/锚点/共享门禁→固定非审计正文→联合重建→回填真实审计。正式结果与旧证据区分，不将猜测写为已证实根因；回填审计不能改变DLL内嵌正文。

## 2. 验证、编码与缓存

日常rebuild/validate显式--background，只跑已核对不显示/激活窗口的路径；两加载项DialogSizesProbe --core仍必需，完整预览/拖动单列。--skip-ui只跳截图不保证后台，透明窗不等后台，不抢焦点/切用户页面/自动打开截图。

| 工具 | 验证内容与边界 |
| --- | --- |
| devlog/markdown/layout门禁 | 四章、三份编号/标记/锚点、三输出及维护唯一；源码携带只允许审计历史build证据缺失，正式strict-evidence要求链接齐全 |
| site_probe | 配置非法输入、HTML结构/资源/脚本语法、版本源、快照关系 |
| audio_probe/download_probe | 隔离DOM与AudioContext、状态/字节/交互，不真实发声/保存文件 |
| workflow_probe/integration_probe | 真实CMD入口参数/提示/退出码、事务失败保护、无旧build及中文/空格/中点/其他cwd路径 |
| file_inventory/cleanup探针 | 必要输入含父verify_shared.py、候选引用/指纹与审阅清单，不能伪造隔离成功记录 |

三批处理UTF-8无BOM/CRLF/chcp65001，Python输出UTF-8；WindowsPowerShell5入口避免中文无BOM误读。网站末尾中文由Python的ASCII转义命令输出，子任务后重设65001；编译诊断按实际编码，不把GBK推广至所有入口。

增量--mode incremental、默认full；build_cache按源码/配置/依赖/规范快照/环境及产物证据摘要判断，缺失或变化重执行、首次无缓存完整。完整不复用；固定私钥/清单双签名/五载荷/网页包字节每轮核。锁内stage收据仅成功事务后提交，last-run-summary及validation-timings记录耗时，复用保留原检查时间，不声称本轮重测。固定图片样例不读取桌面原图。

## 3. 统一交付与失败恢复

固定无EXE快照→以--site-html/--installer-output重建两暂存包→业务/文档/原证书双签名/五载荷验证→attach_installers附本轮EXE→verify_installers对实际包逐字节及版本/名称/长度/SHA-256核对→delivery.publish事务替换两EXE、HTML和current-delivery.json→正式资源复核。

两DLL内嵌WpsShared.Agent.Home.html必须逐字节相同，移除独立页installer-assets后比较网页正文；两个DLL含不同宿主业务，不要求DLL字节相同。编译只接受空包数据区，防安装包包含自身；网站产品按独立身份映射，不将Excel宿主等同Excel-Iterate产品。

缺源码/资产/原私钥停止，不回退旧HTML或换发布者；发布失败恢复上轮正式文件，回滚未完保留恢复文件并报路径。最终审计集中本日志，宿主详细结果链接对应日志；内部current-delivery.json是机器交付记录，不是另建维护文档。用户保存/退出WPS后分别安装才更新加载项内网页；缓存/浏览器接线归加载项共享经验。

## 4. 冗余文件清理

用户实际要求“启动冗余清理”才执行，讨论规则/文档修改/普通构建不触发。默认范围三个项目，外部原图/用户配置/缓存不自动纳入。冗余须生命周期结束且可证明不影响功能、从零重建、签名、必要验证/恢复；同时核依赖闭包、经验归并、隔离排除候选的无旧build成功证据，不能靠文件名/年龄/build目录或无搜索引用判删。

盘点必要输入、当前产物、有效证据、可删历史、未确认五类；按字节从大到小，核摘要与职责，公共副本不可因同摘要删除，项目内移动不算释放。证书私钥/必要输入/未完恢复始终保护，公开CA .pem不按后缀误作私钥。

记录范围/版本/引用/字节/摘要→归并经验修引用→隔离排除候选完整重建与适用验证→`src/tools/cleanup.py --dry-run`生成schema 3清单→审阅→`--apply`读同清单复查→复核保留输入/产物/链接并报实际删除失败及前后字节。目标或源码含父检查器变更需重盘；fixture-state真实结束，cleanup-review绑定源码/目标/独有经验/隔离证据及原日志摘要，不伪造状态。

删除前核绝对路径在明确项目内，不删根、不跟随联接、不碰项目外；旧记录缺恢复信息先保留，失败不降级删保护文件。已授权确认项按范围执行。成功探针仅释放其自建临时资料，失败留诊断恢复。规则共用于联合项目清理，加载项日志保持同等边界。

# 四. XyCabin专属开发经验

## 1. 从零网站与配置接线

从最小“模板+配置→校验/转义→单文件HTML→浏览器交互→行为探针”开始，再接下载/音频/联合交付。site_core.render生成公共正文，template负责结构，控制器处理状态，不手改生成页；普通构建只依项目内资产，无外部CDN/fetch邻近文件。新配置先定义用户可见行为/空态与失败，再生成器校验、模板DOM接线、隔离探针、指南和正式重建。

| 配置 | 接线与边界 |
| --- | --- |
| SITE/TEXT/PRODUCTS | 品牌/文案/指南/版本；TEXT按页序拆NAV/AUDIO/HERO/PROJECTS/GUIDE/VERSIONS/DOWNLOAD_GUIDE/WORKFLOW/FUTURE/FEEDBACK/FOOTER小字典末尾合并，键对应data-text或T.xxx，改名同步DOM |
| THEME | 校验#RRGGBB后CSS变量，action/copy/version/selected/text控制对应局部区域，default_mode仅首次默认 |
| WORKFLOW/FUTURE | 已实现流程与讨论规划分开 |
| DOWNLOADS | word/excel各baidu/quark，空项禁用、仅无账号密码HTTPS，可含查询提取码 |
| DOWNLOAD_GUIDE | 站内相对PNG内嵌、alt非空、steps非空，四段标题/说明/继续/取消文案仍TEXT，缺项停止生成 |
| FEEDBACK | 邮箱→官网HTTPS映射、新标签noopener noreferrer，无映射mailto；复制仅地址，登录发送由用户完成 |

文本转义、JS以JSON序列化，DOM写textContent不拼执行HTML。保持导航、六分区、指南项目切换/搜索/空态/展开、版本筛选、复制/打印/返回顶部可操作；指南用户步骤不要夹构建细节。

## 2. 布局、按钮与弹窗

网页卡片/网格是HTML/CSS布局，不能套用加载项WinForms类或宿主表格语义。局部按钮配色限定立即使用、下载两半、版本复制/筛选，悬停保留对应填充；版本选中背景/边框/加粗显示状态，按钮统一45px最小高/字号行高/内边距，下载三角等高，不改全站按钮。max-width会限制width，反馈区用.wrap宽度/13px字体，宽屏单行、窄屏自然换行。

下载主按钮先展示dialog指引，明确继续才发下载、暂不关闭；dialog不支持或缺指引数据则退回直接下载，不阻断功能。下拉未配禁用，支持键盘/Esc/外部点击/项目切换关闭，初焦点preventScroll。菜单CSS常规245px、min-width:0和视口上限；展开清旧位移后getBoundingClientRect测边界，visualViewport width/offsetLeft优先、clientWidth回退，两边留8px，translateX纠溢；resize/scroll重测，长文换行。只改left/right不足以覆盖两侧按钮和缩放。

最小真实验收：深浅主题/两项目/宽窄屏/展开后改变宽度，菜单左右不出可见区；再测键盘/外部关闭/切换与默认/云下载。download_probe几何替身不等于实际移动浏览器或安装验收。

## 3. 下载、字节校验与能力降级

独立HTML Base64生成Blob+临时a.download，只请求不运行EXE；DLL空数据页按百度→夸克降级，皆空提示，无配置不能冒充有包。按当前项目即时读取，不捕获旧选择。Blob Base64按87380字符（4倍数）分块atob→Uint8Array，避免整份二进制字符串；防重复，异常恢复控件可用，成功请求60秒后revoke，异常/pagehide立即释放ObjectURL。

校验分两层：构建侧site_core.verify_installers真正计算SHA-256并与本轮EXE逐字节核对；浏览器site_downloads只核摘要字段格式、解码总字节数并生成Blob，没有自行计算SHA-256。不得把字段存在写成浏览器已验内容摘要。download_probe正式HTML路径验证Blob字节与安装包；真实保存位置/下载许可由浏览器，提示“已请求下载”不等于已保存。

单配置预览仅附成功交付记录且版本/大小/摘要匹配的包；正式交付从空快照编译，attach_installers只改唯一installer-assets JSON区，embedded_snapshot归一空数据后与DLL网页资源比较。网页正文还可能有生成元数据，按当前snapshot规范比较，不扩大为所有原始HTML字符串都相同。

localStorage try/catch，禁存不影响当前操作；复制失败兼容再显示可选文本，旧剪贴板工具值不能单独证明写入失败。浏览器工具拒file时不得绕策略或用HTTP结果代替；file测试列待验收。

## 4. 声音资产与异步播放

SOUND默认正弦640Hz/70ms、gain0.40/max1.0，仅可信主动按钮click、100ms限频，滚动/悬停/输入/滑块无音效。BACKGROUND默认tranquility、volume0.50/max0.90，音效与背景独立增益再经总静音/压缩器。场景id保afternoon/tranquility，名称描述可改；相对MP3越界/缺失构建失败。

宁静平原是用户原MP3的60～111秒、128kbps/44.1kHz立体声、首尾200ms淡化、仅音频流51秒项目片段；原文件摘要保留，普通重建不访问开发机原盘。午后暖阳合成琴音。Base64转ArrayBuffer后decodeAudioData，不截编码字节冒可解码片段；MP3解码缓存循环，暂停保当前进度、换曲从头，位置不持久化。

xy-home-audio version2将旧百分比除2仅迁移一次、支持小数，旧sound开关保留；用户静音/0/曲目优先，删曲回默认、畸形或禁存储不阻本次。加载试自动播放，suspended静默；若autoplay与play_on_first_interaction都开，首次可信普通导航/指南/主题click补一次，键盘可信click也可，模拟click/音频控件/搜索输入/音量面板排除。音效开关不阻补播，可信事件内先resume、再异步解码，复用未完resume避免多源。

暂停/静音/背景0/换曲/pagehide以代次令牌取消未完播放和补播资格，不能由后续普通点击恢复；手动播放可重试，旧源/调度器释放，手动解码失败显示普通状态仍可用其他网页功能。AudioProbe是隔离DOM/AudioContext状态回归、不发声；真实效果依系统音量/压缩器/录音，不能将增益倍数承诺为听感倍数。

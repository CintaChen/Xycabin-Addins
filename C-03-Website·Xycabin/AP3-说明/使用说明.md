# 一. 打开与使用

　　打开[离线网页](../AP1-程序/XyCabin.html)，可查看 WordUpdater 和 Excel-Iterate 的介绍、指南、版本和开发流程。也可在加载项中点击“Agent-Evo → 开发流程 → XyCabin”，用默认浏览器打开。

　　页面和音乐可离线使用；邮件官网和网盘链接需要联网。安装加载项时仍需先安装 VSTO 运行库、保存文件并退出 WPS。

# 二. 功能操作

## 1. 查阅指南

　　从顶部导航或项目卡片进入“使用指南”，选择项目，搜索功能并展开步骤。可清空搜索、打印当前指南和返回顶部。Excel自定义公式参数窗打开期间可继续操作表格，应用仍处理开窗时的选区。

　　“开始了解”跳到项目介绍，“立即使用”跳到版本与下载区域。页头可切换深浅主题；浏览器允许时会记住选择。

## 2. 下载与版本

　　当前两加载项为0.9.9.1。Excel文件OCR需联网、开通服务并填写密钥；百度支持PDF指定页，结果写入“OCR提取结果”工作表，阿里不支持PDF。网站不收集密钥，详细步骤见[Excel使用说明](../../C-01-ExcelIterate/AP3-说明/使用说明.md)。两产品名称/排序保存后立即生效，格式/控件缩放/弹窗尺寸下次开窗生效，无须重启WPS。

　　选择 WordUpdater 或 Excel-Iterate，再点击“点我下载”；下载对象随当前项目切换。“版本拷贝”复制两项目的版本信息。

　　独立网页携带两个安装包，主按钮或下拉“默认下载”可提取对应 EXE，下载后需自行运行。保存位置和下载许可由浏览器决定；“已请求下载”表示请求已发出，请到下载列表确认文件。点“点我下载”会先显示下载与解锁提示，选“我已了解，继续下载”才真正开始下载，“暂不下载”则关闭且不下载。

　　加载项打开的网页不携带 EXE，主按钮会优先打开已配置的百度、其次夸克网盘。下拉可选下载方式，手机上会自动调整到屏幕内；未配置项不能点击；都未配置时请联系开发者获取安装包。Esc、点击外部或切换项目可关闭下拉。

## 3. 声音与音乐

　　点击右上角音量按钮，可分别调节按钮音效和背景音乐，或全部静音。两首音乐为“午后暖阳”和“宁静平原”，后者是内嵌的 51 秒片段，循环播放。

　　首次使用默认音效 40%、背景 50%，尝试播放“宁静平原”。浏览器阻止自动播放时，会在首次点击导航、指南或主题等普通按钮后再尝试一次；也可手动点播放。主动暂停、静音、降至零或换曲后，普通点击不会重新播放。

　　暂停保留本次进度，换曲从头开始；刷新不保存暂停位置。已保存的开关、曲目和音量优先，实际听感取决于系统音量。

## 4. 修改默认配置后重新打包

　　保存Word、Excel的Configure\_program.py及网站Configure\_Site.py后，运行网站项目的“一键重建并打包.bat”。进入后按1进行增量检查，按2进行完整验证。首次或相关内容有变化时，增量会自动补做需要的步骤；准备正式发布时选2。两种方式都会核对两个安装包与网站内容的一致性，无须先运行两个单项目批处理。

　　构建结束后，保存文件并完全退出WPS，再分别重新安装两个安装包。构建本身不会自动安装。桌面照片不参与默认打包测试，也不会被项目清理自动删除。

# 三. 获取帮助

　　“问题反馈”可打开 QQ/Gmail 邮箱官网，登录和发送由你完成；“复制邮箱”只复制地址。

　　加载项的详细操作见[Excel使用说明](../../C-01-ExcelIterate/AP3-说明/使用说明.md)和[Word使用说明](../../C-02-WordUpdater/AP3-说明/使用说明.md)。网站配置与重建见[开发日志](开发日志.md)，AI 接手入口见[AGENTS.md](AGENTS.md)。

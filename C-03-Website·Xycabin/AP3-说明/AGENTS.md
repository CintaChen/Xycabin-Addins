# 一. 网站开发接手入口

## 1. 阅读顺序

先完整阅读[开发日志](开发日志.md)：[项目档案](开发日志.md#二-项目档案)核对三项目关系/源码/交付，[维护纪律](开发日志.md#三-xycabin项目维护纪律)查写作/验证/清理，[专属经验](开发日志.md#四-xycabin专属开发经验)查配置/弹窗/下载/声音，再核[使用说明](使用说明.md)。本目录为唯一入口，知识以源码文档为准。

## 2. 唯一网站与联合交付

配置、模板、控制器、资产只维护本项目；涉及宿主业务同时读[Excel入口](../../C-01-ExcelIterate/AP3-说明/AGENTS.md)与[Word入口](../../C-02-WordUpdater/AP3-说明/AGENTS.md)。两DLL内嵌无EXE网页资源一致，独立HTML带两包，联合入口验证后事务发布。沿用两产品原版本/固定私钥；不恢复网站或维护文档副本。

## 3. 验证边界

先固定非审计正文，再联合后台重建/验证，最后回填delivery-audit；后台替身、历史及真实file/WPS/云端验收分开记录。构建不安装或关闭WPS。文档修改不触发[冗余清理](开发日志.md#4-冗余文件清理)，实际指令才按正文执行。
